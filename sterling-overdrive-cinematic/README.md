# Sterling Overdrive — Cinematic Edition

A ten-scene interactive, mobile-first web experience made from the approved Sterling-and-Titan concept artwork.

The mobile experience has working contact fields, carrier and bill selection, illustrative Now vs New pricing, a device showroom, a single three-second cinematic phone-selection reveal, wireless plan selection, internet and TV interest, review, and a customer-initiated SMS appointment request in three-hour windows.

Live Realtime AI voice requires `OPENAI_API_KEY` configured in Vercel server-side environment variables. Without it, browser guided speech is available where supported. Never embed API secrets in the client.

Pricing and device illustrations are not guaranteed live carrier offers; orders and appointments are not created by this site. The customer must send their SMS request to London. Final details require verification before sale.
