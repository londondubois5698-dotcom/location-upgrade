iPad / iPhone Safari

1. Bookmark this page in Safari.
2. Edit that bookmark.
3. Rename it Sterling Helper.
4. Replace the bookmark URL with the helper code below.
5. On your active Geopointe/ICL house page, open Bookmarks and tap Sterling Helper.

Best workflow

Run the helper on the active house first and tap Start Sterling for this stop. Sterling opens with that route ID, address and stop ID attached. After the customer confirms first name, last name, phone and email, return to the house and run the helper again. Then Fill + Save + Order verifies the stop before making changes and captures the Partner Order ID.

Safety: The helper only transfers first name, last name, phone and email. It does not handle passwords, SSNs, ID numbers, payment details, PINs or verification codes. If the route stop/address does not match the Sterling packet, it stops.

If Salesforce is showing the ICL page inside an embedded frame on iPad, the helper will offer to open that active ICL route page directly first.
