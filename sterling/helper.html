Sterling ONE V12.1

One bookmark. One Salesforce page. One live voice connection. No QR, no customer phone, no second Sterling tab.

1. Delete the old Sterling Helper bookmark

The old bookmark checks for the V11 helper before loading new code, so keeping it can reopen the broken version.

2. Bookmark this page in Safari

Tap Share → Add Bookmark. Name it Sterling ONE.

3. Edit that bookmark and replace its URL with this code

4. Open Salesforce / ICL and tap the bookmark once

Sterling appears as a small pill on the same page. Tap Start once for microphone permission. After that the realtime connection stays inside the Salesforce page while you move house to house.

What V12.1 changed

V12.1 no longer trusts the route URL for the house. It reads the current visible Salesforce record, including same-origin iframe content. It also uses the iframe's own DOM constructors and events, which fixes the cross-frame bug that stopped V11 from seeing the address and reliably editing fields.
