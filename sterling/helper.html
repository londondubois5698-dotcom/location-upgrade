Sterling Helper V9

Fast setup for your phone or iPad.

iPhone / iPad setup

Important: do not tap the JavaScript code itself. Safari blocks that and shows the “Cannot Run Script” message you saw.

1

Tap Copy Helper Code below.

2

Tap Safari’s Share button → Add Bookmark. Save this page as Sterling Helper.

3

Open Safari Bookmarks → Edit → tap Sterling Helper. Delete the normal web address and paste the helper code into the URL field. Tap Done.

4

Go to an active ICL / Geopointe house. Open Bookmarks and tap Sterling Helper. That is the only place you run it.

After that, the helper watches the active route page, links Sterling to the house, and can auto-fill → Save → Order when the confirmed customer packet comes back.

Desktop setup

Drag this button to your bookmarks bar:

Sterling Helper

What V9 does automatically

When you run the bookmark on an active house, it links that route stop to Sterling, watches for route/address changes, opens Sterling for that stop, receives the confirmed contact packet, checks that it still matches the same house, then can automatically fill the four contact fields, Save, click Order, and capture the Partner Order ID.

If the house does not match, it stops instead of editing the wrong record.

One limitation on iPhone/iPad: Safari does not let a normal website stay secretly active across other apps/tabs or inject itself into Salesforce permanently. The helper becomes autonomous after you tap the Sterling Helper bookmark on the active ICL page. For true always-on phone ↔ iPad background syncing, Sterling needs a private server relay; that is the next step once Vercel storage access is authorized.
