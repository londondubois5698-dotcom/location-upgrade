Sterling Route Helper

One helper. Desktop + iPad.

The helper runs inside your authorized ICL/Salesforce route page, so it works with the desktop record view and the iPad/Lightning layout without relying on screen coordinates.

Install once

Desktop Safari/Chrome: create a bookmark named Sterling Helper, then replace its URL with the copied bookmarklet below.

iPad Safari: bookmark this page first. Open Safari’s bookmarks, tap Edit, select that bookmark, rename it Sterling Helper, and replace its address with the copied bookmarklet.

Field workflow

1. Open the active house in ICL/Salesforce.
2. Tap your Sterling Helper bookmark.
3. Tap Open Sterling for this stop.
4. After Sterling confirms the customer, tap Copy for Salesforce Helper.
5. Return to the ICL/Salesforce tab and tap the helper bookmark again.
6. Tap Run full sequence. It verifies the stop, fills name/phone/email, saves, opens Order, and captures the Partner Order ID.

The helper does not touch SSNs, IDs, PINs, payment information or verification codes. It only works on the customer contact fields and the existing Save/Order controls.
